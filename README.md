# Cabinet Marchal — Maître Cécile Marchal

Site vitrine statique (HTML/CSS) de Maître Cécile Marchal, avocate au Barreau de Strasbourg, recréé sur le modèle de <https://marchal-avocat.webflow.io/>.

## Structure

```
index.html        Page unique (accueil, présentation, domaines d'intervention, contact)
css/style.css     Styles
assets/           Logo, photo, icônes et arrière-plans
```

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python3 -m http.server 8000
```

puis aller sur <http://localhost:8000>.
